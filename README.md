## 这是什么？

LIFE RPG 把你的真实人生经历，转化成一个像素风格的 RPG 角色档案。

- 你的**生日**决定你的等级 —— 活了多少天，就有多少经验值
- 你学过的**技能**是你的能力面板
- 你走过的**每段旅程、每次成长**，都是地图上的一个关卡
- 你的**装备**代表你的状态与身份

不是游戏，是你真实的人生 —— 只是换了一种更酷的方式来呈现。

## 🎮 开始使用

### 方式一：直接打开（推荐）

👉 **[fmiaoz.github.io/GitLife](https://fmiaoz.github.io/GitLife/)**

1. 点击 **「✦ 创建新角色」**
2. 填写名字、生日、选择职业
3. 注册邮箱和密码
4. 开始你的冒险 ⚔️

### 方式二：本地运行

```bash
git clone https://github.com/FmiaoZ/GitLife.git
cd GitLife
open index.html
```

> 无需安装任何依赖，浏览器直接打开即用。

## 💬 设计理念

> *"我们都在玩一场叫做'人生'的游戏，但大多数人没有 HUD（头顶显示器）。"*

传统的简历和日记太无聊了。LIFE RPG 用 RPG 游戏的语言——等级、技能、装备、关卡——重新解读每个人的人生故事。它不是要你假装生活是游戏，而是帮你看见：你已经走了多远，你拥有多少，还有多少可能性在前方。
